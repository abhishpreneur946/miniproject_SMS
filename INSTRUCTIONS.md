# Student Management System

This is a simple and basic student management system built with React.js.

## Features

1. Student Management – Add, edit, and view student details
2. Course & Class Management – Manage courses and assign classes
3. Attendance Tracking – Mark and view attendance
4. Exam & Results – Enter marks and generate report cards
5. Fee Management – Track payments and dues
6. Timetable – Create and view class schedules
7. User Login – Secure login for Admin, Teachers, and Students
8. Teacher Management – Add and manage teacher details
9. Dashboard – Overview of student count, fees, and attendance
10. Search & Filters – Quickly find student or class records

## Getting Started

### Prerequisites

- Node.js and npm installed on your computer

### Installation

1. Clone or download this repository
2. Navigate to the project directory
3. Run the following commands:

```bash
npm install
npm start
```

Or on Windows, simply double-click the `start.bat` file.
